# 当前中继安全核查

2026-10-25 通过服务器只读检查及公网连接反测核实。没有改服务器配置、重启进程或向用户终端发送输入、resize、关闭命令。原始脱敏证据：`.omx/artifacts/relay-security-current/audit-safe.json`。

| 项目 | 核实结果 |
| --- | --- |
| 公网入口 | 443/WSS；证书和 IP SAN 校验通过，实测 TLS 1.3；配置允许 TLS 1.2/1.3 |
| 实际 relay | 仅监听 `127.0.0.1:6770`，由 Nginx 反向代理 |
| 旧 8817 | Nginx 仍公网监听，属于 HTTP 明文；`/ws` 实测 426 拒绝新 WebSocket，`/health` 404 |
| 80 | 实测 308 重定向至 HTTPS |
| 无／错误 Token 查目录 | 可以建立 WebSocket，但授权目录在线房间为 0，收到终端帧为 0 |
| 无／错误 Token 进入实际在线房间 | 均 close 4001，收到终端帧为 0 |
| 正确 Token | 仅目录 HELLO 确认可见授权在线房间；不保存名称、房间码、Token 或终端正文 |

传输加密与鉴权是两层。当前不是端到端加密：Nginx 解密后通过本机连接转发，中继服务器能处理转发内容。8817 的其他软件流量不能因 443 有 TLS 就被称为已加密。公开 UI 包不含私有配置，通过 HTTPS 下载及签名校验；静态更新包无需终端 Token。

同一机器、同一 IP、同一端口不能由两个普通服务直接同时监听；其他软件若只是连接 8817，不会因此抢占监听端口。通过同一 Nginx 按路径分流可共存，改动共享代理配置仍可能影响中继。另一台服务器使用相同端口不构成冲突。

边界：本次没有逐台核查所有旧客户端实际 URL；生产仍报告 `host_enrollment:false`，独立主机所有权凭据的严格迁移尚未上线，不能把现有 Token 鉴权当作该迁移已经完成。共享 Token 应作为共同授权凭据保护，泄露后需要轮换；不在聊天、公开安装包或 Git 中记录。
