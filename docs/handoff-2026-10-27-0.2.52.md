## 3. 本次交付行为及边界

### Windows 文件夹传输

编辑器新增显式“选择文件夹／粘贴文件夹”入口。来源使用有界原生快照，文件经中继暂存及 HTTP 下载到捕获窗口所在主机的项目交换目录，默认是项目 `tmp`。保留目录层级、空目录、中文／emoji 和各级原文件名。

批次固定主机、房间、窗口、会话、epoch、项目绑定和目录身份。丢失 ACK 后查询原批次；停止批次清理尚未提交的上传，不删除已保存文件，已接受任务仍可交付。迟到准备、离线取消、重启恢复及回执补写均有回归证据。

原生来源、编辑器、broker/helper 和公网 HTTP 链路已经测试，但实际用户的 OS 剪贴板／目录选择窗口尚未验收。终端输入行自动 Ctrl+V 文件夹未接线，不能与编辑器显式按钮混为一谈。自动识别嵌套 CLI 当前项目目录也未完成；启动目录／手动目录设置不是该能力的完成证据。

source_path: 发布标签内 `src/supermonoagent/{file_folders.py,file_folder_store.py,file_broker.py,file_companion.py,windows_clipboard.py,desktop_files.py}`、`static/{folder-client.js,folder-composer.js,terminal-composer.js}`；`.omx/artifacts/release-0.2.52/server-public-folder52.json`。

已打包 OP23、stream／grid epoch 和保留区间 resume，仅对显式启用的客户端生效。保留原队列上限 32、惰性回放和四个实际 footer 读取槽。旧环及新增 epoch 环各自有界到 256 KiB。
