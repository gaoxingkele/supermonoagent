# 界面更新 0.2.41

2026-10-25 已发布至现有 HTTPS 签名 stable 频道，序号 `1792916295905657`。Windows 与 Android 使用完整当前快照，原生 API2 不变；不需要安装 APK，没有重启终端 daemon 或 relay。

## 本次交付

- Android Codex 补色规则由 4 条扩为 10 条，覆盖路径、引号、代码片段、错误提示、数字和 Markdown 标记。保留原配色和前四条规则，不给普通论文正文整段染色。
- Windows/Android 不再给 CLI 的淡色推荐文字叠加高亮；保留程序已有前景色、背景色及反色。
- 屏幕方向按钮遵循终端普通／应用光标模式，与实体方向键发送一致的序列。接受推荐仍由对应 CLI 处理，不伪造推荐正文或自动提交。
- 保留 Android 右上角总览入口、默认十六宫格和可选九宫格。

## 验证

- 当前发布相关 pytest：20 passed，包含真实移动页面 DOM/WebGL、中文灰色推荐与方向键，以及发布器验证。
- Node 定向回归：14 passed。
- 本次实际候选 Android ZIP：八种布局通过，默认十六宫格，无终端输入或 resize；公网下载与候选 ZIP 字节相同。
- 公网 HTTPS 证书校验、RSA 签名、归档 SHA256 和全部 17/16 个文件目录均通过。
- JINLONG3090 P1/P2 同一只读快照对比旧／新规则：高亮非空白字符分别由 1 增至 254、由 1 增至 130。不保存论文正文，没有向会话发送输入、resize 或关闭命令。

证据：`.omx/artifacts/ghost-release-0.2.41.xml`、`.omx/artifacts/ghost-release-0.2.41/{publication.json,https-verification.json}`、`.omx/artifacts/remote-claude-highlight/jinlong-visible-analysis.json`。

手机上的下载、重载与实际视觉效果仍由设备热更新验收；发布成功不等于设备已更新。服务器暂未提供远端 daemon 的精确版本，不能把高亮差异断言为主机安装包过旧。
