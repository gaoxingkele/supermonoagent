# 0.2.82 终端管理与 Android 升级

Android 标准包使用 `dev.supermonoagent.mobile`，版本码 84。运行 0.2.78 标准包的用户可使用同签名 APK 覆盖升级。首次安装或升级时由 Android 核对安装包，现有数据保留情况已在 Android 15 模拟器验收。驾驶舱反馈实验包有单独的包名。 [Android 安装包](../dist/android/0.2.82/SuperMonoAgent.apk) · [SHA-256](../dist/android/0.2.82/SuperMonoAgent.apk.sha256)

## 结束与改名

- **Windows。** 当前终端头部的「×」关闭查看页；「结束」在确认后请求后台终止所选会话。新版 Windows 后台按进程身份确认退出。如果退出失败，保留会话并返回错误。兼容旧后台时，以其返回的目录为准。
- **Android。** 打开「☰ → 工作空间 → 管理当前终端」。选择「修改窗口名称」，核对电脑和原窗口标题后保存；该窗口内的会话共用窗口名。选择「结束终端进程」，核对窗口和会话后确认。其他会话继续工作。
- **目录计数。** 房间监控分别显示有会话的窗口数、终端数和空窗口数，侧栏按该主机的会话数显示。查到的 Ewan 目录为 12 个窗口条目，其中 3 个为空、9 个各有一个会话。这个目录本身没有操作系统 PID 状态。结束命名窗口里的最后一个会话后，其空容器可以保留。

## 验证范围

桌面浏览器实际点击取消和确认，Windows 上用被测 PowerShell 的内核句柄验证退出，另一个测试 PowerShell 持续运行。服务端另测正常挂在同一终端的前台子 PowerShell，父子均已退出。还覆盖了故意终止失败、过期请求、并发关闭和其他查看端的目录刷新。Android 15 模拟器完成 0.2.78/code80 → 0.2.82/code84 覆盖安装，保留应用身份和连接偏好。被测终端改名时 PID 稳定；结束时有且仅有一次关闭请求，相邻 PowerShell 保留，PTY 输入及 resize 都为零。实体手机的安装状态需在该设备上核对。
