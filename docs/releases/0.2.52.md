# SuperMonoAgent Windows 0.2.52

The Windows installer and Python package source both use **0.2.52**. Git tag
`v0.2.52` identifies the matching source and complete `dist/windows/0.2.52`.
The runtime build manifest records source commit
`0f48295419685bbebce800084cbb310973f079d9`; subsequent release commits add only
documentation and the verified artifacts.

This release adds explicit folder selection/paste in the editor, preserving
directory hierarchy, empty directories and child filenames in the selected
host's project exchange directory. Transfers keep the original host/session/
project binding; interrupted acknowledgements are queried rather than blindly
uploaded again. Stopping a batch preserves saved files and already accepted jobs.
The receiving helper and relay file service must support folder capabilities.

Opt-in history context and retained-interval resume preserve stream/grid identity
without changing legacy clients or increasing the 32-frame replay queue.
This is not recovery for Grok screen content already missing from retained output.

The public installer contains no private default Token. The restricted installer
portal supplies the default configuration; existing installations keep their
Token and file-exchange settings. Install with `Install.cmd`. If the previous
desktop interface is still running, close that interface and reopen the new
shortcut; the background terminal sessions remain separate. This publication
does not forcibly restart existing user terminal daemons or file helpers.
