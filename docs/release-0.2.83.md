# 0.2.83 驾驶舱默认连接与精简电脑列表

发布日期：2026-11-25。Windows、Android 和签名界面统一使用 0.2.83；Android 标准包版本码为 85，包名与签名保持不变。

## 驾驶舱

- 服务地址默认填为 `wss://117.50.48.22/hub/view`，项目默认填为 `*`（全部授权项目）。已保存的选择优先。
- 地址和项目不需要手工推导，只需填写运维签发的只读凭据；终端 Token 不会复用为驾驶舱凭据。
- 连接后默认显示「待处理」任务列表，可直接查看任务、证据、额度和对话内容。

## 左侧电脑列表

- 第一行显示「机器名（N 个终端）」。
- 第二行显示连接状态、往返延迟和上下行带宽。
- 房间号不再占用列表空间；两行均禁止额外换行，空间不足时省略。

## 发布与验证

桌面和安卓浏览器测试覆盖默认值、任务内容及原有对话、额度和 mylib 视图；真实 MCP 与 WebSocket 跨仓库用例通过。发布前另跑电脑列表真实浏览器回归，并核对 APK、Windows 安装包、签名界面 ZIP 与公网清单的 SHA-256。签名 stable 界面发布会同时更新 Windows 和 Android 页面；原生 APK 仍需用户覆盖安装，不将界面发布等同于设备已经安装。
