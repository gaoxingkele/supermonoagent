# Windows 左侧栏窗口状态灯

2026-10-22。Windows 桌面和浏览器 workspace 的左侧窗口行现在沿用手机端状态含义：

- 红色：所属电脑连接已断开。
- 黄色：连接正常，暂未收到新的终端输出。
- 闪烁绿色：最近 1.8 秒内收到该终端的实时输出。

圆灯使用 8px 固定直径和深色描边，在默认深色底及自定义窗口底色上保留轮廓。窗口行在原缩进基础上再右移 12px，预留圆灯与文字间距，明确分组层级。标签改名、配色和右键菜单继续使用原逻辑。

状态按电脑和原始会话 ID 分别记录；历史快照不触发绿灯，断开与重连清除旧活动记录。黄色是“暂未收到新输出”，并不证明 AI 已完成任务或正在等待输入。状态灯使用已有输出流，没有增加未打开终端的订阅。系统选择减少动态效果时，绿灯保留颜色并停止闪烁。

代码落点：`src/supermonoagent/static/workspace.js` 的活动记录、`updateSessionDots()`、`renderTree()` 与生命周期清理；`workspace.css` 的圆灯、动画和缩进。没有更改手机资源、后台协议或终端输入。

回归：`tests/test_workspace_activity.py` 使用隔离 FakePTY 和真实浏览器，验证历史回放、绿灯只影响对应窗口、空闲黄灯、断线红灯、重连、缩进边界及减少动态效果；测试没有发送终端输入。截图：`.omx/artifacts/sidebar-activity/`。

相关 Python 回归 16 项通过；Node 32 项通过。状态灯按 300ms 批量更新，实时输出帧只记录时间戳，避免高频刷屏时反复扫描侧栏 DOM。实际 EXE 的源码哈希与侧栏灯、390～1920 像素确认网格检查记录在同目录 `packaged-smoke.json`。本轮仅调整客户端显示，不增加依赖或输出订阅。

新版包：`dist/windows-sidebar-status/`；双击 `02-Orca-Workspace.vbs` 打开桌面，或 `01-Browser.vbs` 打开浏览器。保留整个目录。现有终端后台无需重启；已经打开的旧版页面需要重新打开新版客户端。
