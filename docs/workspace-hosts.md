# 按房间码增加电脑工作区

点击左侧“工作区 · 电脑”旁的“＋”，输入工作区名称和对应电脑的房间码。中继地址优先带出当前连接或本机已配置的中继；对应服务要求身份验证时，再填写这台电脑的访问 Token。点击“保存并连接”后，自动读取并打开目标电脑现有的终端页签。

左侧按项目、电脑、分组与会话聚合。每台保存的电脑保持独立连接；点击名称选择电脑，不会断开其他电脑。初始选中的电脑自动打开现有终端，其他电脑先获取目录，在首次选择时打开其终端。省略号可编辑或移除连接记录。移除、切换或关闭客户端都不会结束电脑上的终端。“终端分组”旁的另一个“＋”用于当前电脑内部的新建分组，和增加电脑工作区分开。

电脑名称、地址、房间码保存在此客户端。每台电脑使用单独且绑定地址/房间码的 Token，默认只存在当前标签页；勾选“在此设备保存此电脑的 Token”才保存到本地持久存储。不会自动拿本机 Token 去登录另一台电脑。修改连接目标会清除旧凭证、视图与目录；重连采用 generation 检查使旧回调失效。内部使用 JSON 元组隔离不同电脑相同的会话编号，线上会话 ID 保持原样。

修改文件：`src/supermonoagent/workspace.py`、`static/workspace.js`、`static/workspace.css`，以及 `desktop.py` 的浏览器 `--workspace` 入口。测试见 `tests/test_workspace_hosts.py`、`tests/test_desktop.py`；两台隔离主机共用本地中继的测试验证新增、刷新保留、切换、Token 隔离、相同会话编号下的输出/输入路由和移除记录。

当前验证与产物见 [本轮验证记录](todo-completion.md)。早期表单截图：`.omx/artifacts/workspace-hosts/add-workspace.png`。

当前 TD-001～TD-006 包在 `dist/windows-global-workspace/`。双击 `02-Orca-Workspace.vbs` 打开桌面，或 `01-Browser.vbs` 在浏览器打开同一新版工作区。两者通过隐藏启动助手运行，不保留多余控制台。桌面启动后显式显示 WebView。新版顶部不再显示“经典版”入口；既有经典路由保持兼容，确需使用时可显式传入 `--legacy`。

没有替用户添加未知房间，也没有更新远端 daemon 或公网中继。旧远端若不支持多会话工作区协议，连接时会显示协议升级提示。已有工作区连接列表保存在各客户端的浏览器存储中，不会自动在不同浏览器之间共享。
